×1
예제를 고르고 시작을 누르세요. 모든 시연은 수동 조작과 동일한 기계 명령(슬라이더·크랭크·캐리지·클리어링)만 사용합니다.

    설정 슬라이더 Setting sliders

    3D 손잡이를 위아래로 끌거나, 열을 선택해 ↑/↓ 키로도 조정합니다. 슬롯 번호는 오른쪽부터 1–8.

    크랭크 Crank

    크랭크는 항상 시계 방향으로만 돕니다. 3D 크랭크 손잡이를 끌어 직접 돌릴 수 있고, 중심 허브를 위/아래로 끌면 감산/가산 위치로 바뀝니다.

    캐리지 Carriage

    위치 버튼은 들기 → 인덱스 회전 → 내리기를 순서대로 수행합니다. 들린 상태에서는 크랭크가 잠깁니다.

    클리어링 링 · 반전 레버 Clearing / Reversing

    레버는 캐리지를 들어야 움직이며, 밝은/어두운 다이얼 경계의 홈(check)에 있어야 캐리지를 내리고 크랭크를 돌릴 수 있습니다.

    초기화 오류

    3D 모델의 부품을 클릭하거나 ‘부품’ 탭에서 고르세요.

      자체 검증 Self-tests

      사용자의 기계와 분리된 엔진 인스턴스에서 실행되며, 기대값은 독립적인 BigInt 산술로 계산합니다. 콘솔: CurtaTests.run({randomCount:1000})

      기하 맞물림 진단 Rendered engagement audit

      실제 3D 부품(기어·드럼 톱니·자리올림 피니언·텐스 벨)의 월드 좌표를 조립 상태(분해 오프셋 제거)로 측정해, 각 기어가 겹치는 톱니판의 톱니 수가 엔진이 일정표에 넣는 맞물림 수와 같은지, 작동한 피니언만 벨 톱니 평면에 있는지 확인합니다. 평면·반경 해석 검사이며 접촉 역학 해석은 아닙니다.
